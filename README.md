# Retail Sales Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Sample Superstore dataset using Python. The goal is to understand retail sales and profit patterns, identify business trends, and discover useful insights through data analysis and visualization.

## Dataset
- **Dataset:** Sample Superstore
- **Source:** [Kaggle – Sample Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
- **Records:** 9,994 rows
- **Columns:** 21

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Analysis Performed
- Dataset structure and overview
- Missing value analysis
- Summary statistics
- Categorical data analysis
- Sales analysis by product category
- Profit analysis by region
- Sales distribution analysis
- Discount and profit relationship
- Monthly sales trend analysis

## Key Findings
- Technology generated the highest total sales among the product categories.
- The West region recorded the highest total profit.
- Most sales transactions had relatively low sales values.
- Higher discounts were generally associated with lower profits.
- Overall monthly sales showed an upward trend from 2014 to 2017.

## Conclusion
The analysis highlights important patterns in retail sales and profitability. These insights can help identify strong-performing product categories, profitable regions, and opportunities to improve discount strategies.
